# Stigma & Service Initiation 

This project uses data from a larger, randomized controlled clinical trial to examine how stigma propspectively impacts the initiation of community-based substance use treatment services following release from prison. 

# Overview

Will be using data from more than 500 people across three states to assess whether percieved stigma impacts engagement in MOUD, substance use treatment, and menthal health treatment. 

# Data

The data associated with this project are confidential and will not be included in this repository.
